# Tic-Tac-Toe Game

A simple two-player Tic-Tac-Toe game built with React.

## Features
- 3×3 board
- X and O take turns
- Winner detection
- Draw detection
- Reset button
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL shown in your terminal.

## Build

```bash
npm run build
```

The production files are created in `dist`.

## Netlify

Build command: `npm run build`  
Publish directory: `dist`

These settings are also configured in `netlify.toml`.
